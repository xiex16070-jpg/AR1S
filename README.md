# AR1S

> 基于 [Mineradio](https://github.com/XxHuberrr/mineradio) 的个人修改分支 — 一台 Windows 桌面沉浸式音乐播放器，把天气电台、多平台搜索、歌词舞台、粒子视觉和 3D 歌单架揉进同一个私人音乐空间。

本分支在 Mineradio 原有功能之上，额外添加了 **Bilibili（B站）外挂登录与搜索播放**、**本地文件夹递归扫描播放**，以及一些贴合个人喜好的界面与交互调整。

## 分支新增特性

- **B站外挂登录** — 支持扫码 / Cookie 登录 B站，读取收藏夹，搜索 B站视频并以视频画面或纯音频模式播放
- **B站搜索结果** — 展示封面、标题、UP主、播放量、时长，一键加入播放队列
- **视频播放模式** — 可切换至纯 B站搜索模式，隐藏网易云/QQ 音乐入口
- **本地歌曲扫描** — 歌单面板新增"本地扫描"标签，选择文件夹递归扫描 MP3 / FLAC / WAV / OGG / M4A，直接播放和加队列
- **DIY 背景持久化** — 自定义背景图片/视频走服务端磁盘存储，不受浏览器 localStorage 配额限制
- **壁纸模式** — 全屏壁纸窗口，背景视频渲染、歌词居中、粒子动画贴桌面层

## Mineradio 原有核心特性

- Open-Meteo 天气电台，根据位置、城市和天气 mood 生成播放队列
- 网易云音乐账号登录、搜索、歌单、播客
- QQ 音乐搜索、登录态与音源补充
- 3D 歌单架，右键唤起，支持歌单队列浏览
- 基于节奏的电影镜头视觉系统
- 歌词舞台、自定义歌词、歌词位置与视觉控制
- GitHub Releases 自动更新检测

## 安装与使用

在 [Releases](https://github.com/xiex16070-jpg/AR1S/releases) 页面下载最新 AR1S-x.y.z-Setup.exe 安装包，双击安装即可。安装包会自动创建桌面快捷方式。

---

## 开发运行

`ash
npm install
npm start
npm run build:win
`

桌面版入口由 Electron 主进程加载本地服务。
pm run build:win 生成 Windows NSIS 安装包至 dist/。
